# Axeom Pack 188 ? Studio Desk

A mobile-friendly studio dashboard for client records, payment reconciliation, edit requests, and CSV/TXT/ZIP uploads.

## Deploy with Vercel

Import this GitHub repository into Vercel. The app is plain static HTML: framework Other, repository root as the root directory, no build command, and output directory `.`. Configuration is included in `vercel.json`.

`index.html` includes the fake challenge data and all runtime dependencies. No API key, backend or CDN is required. Changes and uploaded records are stored in each visitor's browser. Approval produces a draft; nothing is sent automatically.

The full submission archive separately contains the editable source, original inputs, independent analyses, documents and test evidence. Jev evaluation remains blocked by the TypeSafe credit requirement; no Jev accuracy result is claimed.
